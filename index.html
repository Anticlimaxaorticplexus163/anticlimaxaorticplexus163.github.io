📖 About This Project

neo-cs-mc brings your favorite internet memes directly into your Minecraft world. You can replace standard game sounds with custom clips. This tool allows you to trigger specific audio files through chat commands or jukebox blocks. It functions as a lightweight modification for the Java Edition of the game.

🕹️ How to Use

Once you are inside the game, the mod loads automatically. You can interact with the system using the chat bar by pressing the T key. Type a command to view available meme sounds. You can assign these sounds to jukeboxes by placing a record inside the block. The system detects the record type and plays your custom audio file instead of the default track.

If you encounter issues, ensure that your sound settings in the game are at an audible level. The mod uses the game's Music and Master volume sliders to control the meme output.

🛠️ Troubleshooting

If the sounds do not play, verify that you have extracted the necessary audio files into the correct folder created in your .minecraft directory. Ensure that the file format for your custom clips is .ogg, as this is the standard format for the game engine. Restarting your game after adding new sound files ensures the system recognizes your updates.
